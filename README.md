# صلاتي

تطبيق ويب عربي لمواقيت الصلاة والقرآن والأذكار والقبلة والختمة، مصمم ليعمل كتطبيق ويب تقدمي (PWA) على الجوال.

## التشغيل محليًا

شغّل أي خادم ملفات ثابت داخل مجلد المشروع، ثم افتح `index.html` عبر الخادم. بعض الميزات مثل الموقع والإشعارات تحتاج `localhost` أو اتصال HTTPS.

## الملفات

- `index.html`: التطبيق والميزات الأساسية الحالية.
- `styles-v2.css`: طبقة التصميم المحسنة والمتجاوبة.
- `app-v2.js`: تحسينات الوصول وتجربة الموقع والعلامة البصرية.
- `manifest.json`: إعدادات تثبيت التطبيق على الهاتف.

## النشر

المشروع متوافق مع GitHub Pages ولا يحتاج خطوة بناء.
